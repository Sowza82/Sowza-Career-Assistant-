## Sowza Career Assistant

### Descrição

Projeto de Inteligência Artificial baseado em **RAG (Retrieval-Augmented Generation)** desenvolvido para responder perguntas sobre a trajetória profissional de Tatiane Souza utilizando uma base de conhecimento personalizada.

O projeto está sendo desenvolvido como parte do **Challenge Alura Agente 2026**, etapa final do programa ONE AI for Tech (prazo: 19/08/2026).

### Objetivo

Construir um agente inteligente capaz de responder perguntas utilizando documentos estruturados sobre formação, certificações, projetos, habilidades e experiências profissionais.

### Tecnologias

- Python
- FastAPI
- TF-IDF
- LangChain
- API Anthropic (Claude)
- ChromaDB
- Google Colab
- Render.com (deploy)
- Git
- GitHub

### Funcionalidades

- Leitura automática de documentos Markdown
- Geração de embeddings
- Banco de dados vetorial com ChromaDB
- Busca semântica
- Pipeline RAG
- API construída com FastAPI

### Principais Aprendizados

- Inteligência Artificial Generativa
- Engenharia de Prompt
- LangChain
- Bancos Vetoriais
- Recuperação Semântica (RAG)
- Deploy em nuvem (Render.com)

### Desafios

- Construção da base de conhecimento
- Organização da documentação
- Geração de embeddings
- Otimização das respostas do agente

### Status

Em desenvolvimento

### Repositório

https://github.com/Sowza82/sowza-career-assistant

### Deploy

Em desenvolvimento (planejado no Render.com)

## HR Buddy

### Descrição

Agente conversacional baseado em **RAG**, desenvolvido como projeto capstone do programa **ONE Imersão Agentes de IA**.

### Objetivo

Construir um agente de IA capaz de responder perguntas de colaboradores sobre políticas e informações de RH, utilizando uma base de conhecimento documental.

### Tecnologias

- n8n
- Cohere
- MySQL
- Railway (hospedagem do banco de dados)
- Telegram (Bot API)

### Funcionalidades

- Fluxo de automação via n8n
- Respostas via chatbot no Telegram
- Recuperação de informações de uma base de conhecimento de RH
- Integração com banco de dados MySQL

### Principais Aprendizados

- Construção de agentes RAG com ferramentas low-code (n8n)
- Integração de LLMs via API (Cohere)
- Hospedagem de banco de dados em nuvem (Railway)
- Integração com bots de mensageria

### Desafios

- Estruturação da base de conhecimento de RH
- Configuração do fluxo de automação
- Integração entre n8n, banco de dados e Telegram

### Status

Concluído (18/06/2026)

### Repositório

github.com/Sowza82/Imersao-Agentes-de-IA

### Deploy

Bot ativo via Telegram
