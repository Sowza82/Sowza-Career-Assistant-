# Sowza Career Assistant

### Descrição

Projeto de Inteligência Artificial baseado em RAG (Retrieval-Augmented Generation) desenvolvido para responder perguntas sobre a trajetória profissional de Tatiane Santos de Souza utilizando documentos como currículo, certificações, projetos e portfólio.

### Objetivo

Demonstrar conhecimentos em Inteligência Artificial, LangChain, ChromaDB, Streamlit e Oracle Cloud Infrastructure por meio de um agente inteligente voltado para consultas sobre a carreira profissional.

### Tecnologias

- Python
- LangChain
- ChromaDB
- Google Gemini
- Streamlit
- Oracle Cloud Infrastructure
- Git
- GitHub

### Funcionalidades previstas

- Leitura de documentos
- Geração de embeddings
- Banco vetorial
- Busca semântica
- Respostas utilizando RAG
- Interface web
- Deploy em nuvem

### Status

Em desenvolvimento
