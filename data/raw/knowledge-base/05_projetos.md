# Sowza Career Assistant

## Descrição

Projeto de Inteligência Artificial baseado em **RAG (Retrieval-Augmented Generation)** desenvolvido para responder perguntas sobre a trajetória profissional de Tatiane Souza utilizando uma base de conhecimento personalizada.

O projeto está sendo desenvolvido como parte do **Challenge Alura Agente 2026**, etapa final do programa ONE AI for Tech, com prazo de entrega em 19/08/2026.

---

## Objetivo

Construir um agente inteligente capaz de responder perguntas utilizando documentos estruturados sobre formação, certificações, projetos, habilidades e experiências profissionais.

---

## Tecnologias

- Python
- LangChain
- Google Gemini
- ChromaDB
- Streamlit
- Google Colab
- Git
- GitHub

---

## Funcionalidades

- Leitura automática de documentos Markdown
- Processamento e divisão de documentos em chunks
- Geração de embeddings
- Banco de dados vetorial com ChromaDB
- Busca semântica
- Pipeline RAG
- Interface conversacional com Streamlit

---

## Principais Aprendizados

- Inteligência Artificial Generativa
- Engenharia de Prompt
- LangChain
- Bancos Vetoriais
- Recuperação aumentada por geração (RAG)
- Organização de bases de conhecimento
- Desenvolvimento de agentes inteligentes

---

## Desafios

- Construção da base de conhecimento
- Organização da documentação profissional
- Configuração do pipeline RAG
- Geração de embeddings
- Otimização das respostas do agente

---

## Status

Em desenvolvimento

---

## Repositório

<https://github.com/Sowza82/sowza-career-assistant>

---

## Deploy

Em desenvolvimento.

Planejado para publicação em ambiente cloud.

# HR Buddy

## Descrição

Agente conversacional baseado em **RAG (Retrieval-Augmented Generation)** desenvolvido como projeto capstone do programa **ONE Imersão Agentes de IA**.

---

## Objetivo

Construir um agente de Inteligência Artificial capaz de responder perguntas de colaboradores sobre políticas e informações de Recursos Humanos utilizando uma base de conhecimento documental.

---

## Tecnologias

- n8n
- Cohere
- MySQL
- Railway
- Telegram Bot API

---

## Funcionalidades

- Fluxo de automação utilizando n8n
- Respostas via chatbot no Telegram
- Recuperação de informações de uma base de conhecimento de RH
- Integração com banco de dados MySQL

---

## Principais Aprendizados

- Construção de agentes RAG utilizando ferramentas low-code
- Integração de modelos de linguagem via API da Cohere
- Hospedagem de banco de dados em nuvem
- Integração entre automação, banco de dados e bots de mensageria

---

## Desafios

- Estruturação da base de conhecimento de RH
- Configuração dos fluxos de automação
- Integração entre n8n, banco de dados e Telegram

---

## Status

Concluído (18/06/2026)

---

## Repositório

<https://github.com/Sowza82/Imersao-Agentes-de-IA>

---

## Deploy

Bot ativo via Telegram.
